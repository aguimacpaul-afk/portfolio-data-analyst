📊 Foodpanda Customer Analysis

Este proyecto es parte de mi portafolio como Data Analyst, donde exploro y analizo un dataset de clientes, pedidos y restaurantes de la plataforma Foodpanda.
El objetivo principal es aplicar técnicas de SQL y Pandas para extraer insights valiosos relacionados con el comportamiento de los clientes, la fidelización y la relación con los restaurantes.

🎯 Objetivos del Análisis

Identificar los clientes más rentables y su gasto total.

Analizar el churn (clientes inactivos) por ciudad y factores relacionados.

Evaluar el ticket promedio y su relación con la lealtad.

Medir la variabilidad en los ratings por categoría de restaurante.

Explorar tendencias temporales (órdenes por mes/día) y patrones de fidelización.

🛠️ Herramientas utilizadas

Python (Pandas, Matplotlib, Seaborn)

SQL (DBeaver/PostgreSQL)

Jupyter Notebook para documentación y análisis exploratorio

Git/GitHub para control de versiones
