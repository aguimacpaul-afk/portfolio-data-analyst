📀 SQL Practice – DVD Rental Database
📌 Descripción

Este proyecto contiene una serie de consultas en SQL (PostgreSQL) realizadas sobre la base de datos DVD Rental.
El objetivo principal es practicar y dominar conceptos intermedios y avanzados de SQL, aplicables al análisis de datos y entornos de bases de datos relacionales.

🎯 Objetivos de la práctica

Reforzar el uso de JOINs para combinar múltiples tablas.

Trabajar con funciones de agregación (SUM, COUNT, AVG) y cláusulas GROUP BY + HAVING.

Implementar CTEs (WITH) y tablas temporales para organizar consultas complejas.

Aplicar funciones de ventana (RANK(), DENSE_RANK(), ROW_NUMBER()) para obtener rankings y particiones.

Practicar filtros avanzados con EXISTS y NOT EXISTS.

Desarrollar consultas que respondan a escenarios reales de negocio.

🛠️ Tecnologías utilizadas

PostgreSQL

pgAdmin / DBeaver para ejecutar y visualizar consultas

GitHub para control de versiones y portafolio
