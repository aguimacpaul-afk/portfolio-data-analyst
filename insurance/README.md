📌 Project Overview

This project demonstrates a complete workflow of a machine learning regression task, from data preprocessing to model evaluation and interpretation. It was designed as a hands-on exercise to strengthen my data analysis and machine learning skills using Python.

🛠️ Tools & Libraries

Python

NumPy for transformations and scaling

Pandas for data handling

Matplotlib / Seaborn for visualization

scikit-learn for regression models and evaluation

🔄 Tasks Performed

Data Preprocessing

Handled missing values and basic cleaning.

Normalized bmi column using Min-Max Scaling with NumPy (without sklearn).

Exploratory Data Analysis (EDA)

Generated descriptive statistics.

Visualized distributions and relationships between variables.

Modeling

Implemented Linear Regression to predict the target variable.

(Optional) Tested Decision Tree Regressor for feature importance analysis.

Evaluation Metrics

R² Score (Coefficient of Determination): measured how well the model explains the variance.

Mean Squared Error (MSE): evaluated prediction accuracy.

Feature Importance

For the Decision Tree model, visualized the relative importance of each variable.
